# Projeto Old Steve - Refatoração

Atividade proposta em aula com o objetivo de revisar e aplicar conceitos da **Programação Orientada a Objetos (POO)**.

O projeto consiste na refatoração de um código procedural, utilizando classes, objetos, atributos e métodos para organizar melhor sua estrutura.

## Objetivo

Praticar a transformação de um código procedural para POO, mantendo o funcionamento original do programa.

Com isso, o código fica mais organizado e facilita futuras alterações e reutilizações.
