# Projeto Stardew Maneger

Projeto desenvolvido em aula com o objetivo de praticar conceitos da **Programação Orientada a Objetos (POO)**.

O projeto simula um sistema simples de gerenciamento de animais de uma fazenda, utilizando classes, herança e interfaces para representar diferentes tipos de animais.

## Objetivo

Praticar a criação e organização de classes em Java, aplicando conceitos de **POO** em um sistema simples e interativo.
